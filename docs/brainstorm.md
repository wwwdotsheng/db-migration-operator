# 功能脑暴清单

以下仅列举可能实现的功能，不设范围、优先级或交付承诺，包含现有功能的完善方向。

## 迁移声明与资源模型

- SQL 脚本迁移、声明式目标 schema、自动生成差异迁移。
- 独立数据库连接、迁移计划、发布批次、审批与执行记录资源。
- Expand、数据回填、Contract 多阶段迁移。
- 多前置版本、跨迁移依赖、依赖图、循环依赖检测。
- 数字版本、语义版本、时间戳版本、命名版本。
- 内联、ConfigMap、Git、OCI 制品、对象存储 SQL 来源。
- 迁移模板、参数绑定、参数校验。
- SQL checksum、迁移身份、目标数据库身份校验。
- 执行后关键字段不可变、变更后重新规划和预演。
- CRD 默认值、准入校验、多版本转换、kubectl 状态列。

## 执行一致性

- 数据库级串行执行、跨控制器和跨集群执行互斥。
- 执行者身份、租约、心跳、fencing token、遗留锁清理。
- 版本重复、缺失、乱序、内容冲突检测。
- 逐语句结果、耗时、日志、检查点。
- 执行前置条件、后置条件、实际结构核对、语义幂等。
- SQL 已执行但账本未确认的不确定状态处理。
- 事务性 DDL 执行、非事务性 DDL 分步执行。
- 瞬态与永久错误分类、退避、抖动、重试预算。
- 连接、语句、锁等待和整体迁移超时。
- 暂停、恢复、取消、取消结果确认、优雅停止和任务交接。
- 连接池复用与关闭、数据库和租户级并发限额。
- 失败后停止依赖迁移、执行前重新检查依赖与审批。
- 人工执行、外部执行器结果统一登记。

## 故障恢复

- 控制器重启、Pod 驱逐、节点故障恢复。
- 数据库重启、主从切换、断网恢复。
- 从最后确认步骤继续、核对未知执行结果。
- 实际结构、数据库账本、Kubernetes 状态对账。
- Failed 显式重试、恢复请求、恢复计划预览与审批。
- 人工确认步骤完成、跳过步骤、修正记录。
- 修复版本、前滚补偿、失败诊断和处理建议。
- 可选回滚脚本、回滚检查、回滚预演。
- 备份恢复、时间点恢复编排。
- 恢复审计、高风险操作二次批准。
- 孤儿记录清理、资源删除执行保护、CR 重建历史关联。

## 影子预演

- 完整结构导出、严格导入检查。
- 表、索引、约束、视图、触发器、函数、存储过程验证。
- 产品、版本、字符集、排序规则匹配。
- 结果绑定 generation、SQL checksum、结构指纹。
- 结果过期、结构变化后重新验证。
- 与正式执行共享 SQL 处理和幂等规则。
- 预演后结构与目标结构对比。
- 空结构、采样数据、完整副本预演。
- 脱敏、抽样、合成数据、约束兼容性验证。
- 快照、数据库分支、克隆环境接入。
- 新旧应用查询和版本兼容性验证。
- 环境池、镜像预热、预演缓存。
- Job 资源配额、网络隔离、生命周期管理。
- 进度、完整日志、失败报告、失败环境保留。
- 恢复流程和回滚流程预演。

## SQL 分析与风险控制

- 多方言解析、格式化、多语句和存储过程脚本处理。
- 破坏性 DDL、全表更新、无条件删除检测。
- 类型缩窄、重命名、默认值变化和数据丢失风险识别。
- 锁类型、表重写、索引重建、磁盘需求估计。
- 大表、热点表、高流量时间段识别。
- 风险分级、解释、规则配置、允许列表、禁止列表。
- 命名、主键、索引、字符集、字段规范检查。
- 多步迁移拆分、安全改写建议。
- Expand-Contract 兼容性、回填完成、旧应用退役检查。
- 应用、表、字段、查询影响分析。
- 规则例外申请、有效期、审计。
- 权限与能力检查、外部变更和 schema 漂移检测。

## 在线变更与数据回填

- 原生在线 DDL 能力检测和策略选择。
- gh-ost、pt-online-schema-change 接入。
- PostgreSQL 并发索引和分阶段约束验证。
- 在线工具进度、暂停、取消、恢复。
- 表切换审批、维护窗口控制。
- 分批回填、主键游标、检查点。
- 批次大小、速率、并发动态调整。
- 根据负载、磁盘、锁等待、复制延迟限速。
- 数据校验、差异检测、补偿修复。
- 双写、读路径切换、旧字段退役。
- CDC、增量同步、容量和耗时估计。
- 业务指标异常自动暂停或终止。

## 数据库与连接

- MySQL、PostgreSQL、MariaDB。
- SQL Server、Oracle、SQLite、CockroachDB。
- TiDB、OceanBase、YugabyteDB、ClickHouse。
- 云托管数据库、云代理、数据库扩展和能力检测。
- 多 schema、search_path、分库分表、分片和多租户迁移。
- 主从拓扑、可写节点选择、切换后连接重建。
- 私有网络、SSH 隧道、代理连接。
- TLS、双向 TLS、证书轮换。
- IAM、短期令牌、动态凭据。
- 驱动插件、能力声明、自定义执行器。

## 发布编排与 GitOps

- 开发、测试、预发布、生产逐级晋升。
- 跨环境迁移制品一致性校验。
- Argo CD、Flux、Helm、Kustomize 集成。
- GitHub Actions、GitLab CI、Jenkins、Tekton 集成。
- 应用发布依赖编排、发布前 Expand、退役后 Contract。
- 健康检查、执行门禁、Canary、分批租户发布。
- 多数据库部分成功处理、批次失败策略。
- 定时执行、时区、维护窗口、冻结期、紧急变更。
- 发布计划预览、顺序展示、PR 检查和报告同步。
- Git 提交、制品、执行记录关联、制品签名与来源验证。

## 审批、权限与审计

- 项目、环境、数据库、操作级授权。
- 申请、审核、执行职责分离。
- 单人、多人、分级、基于风险审批。
- 审批绑定内容和环境、内容变化撤销审批。
- 审批有效期、委托、升级、紧急授权、事后复核。
- 防篡改审计、导出、检索、保留策略。
- Secret 最小权限、凭据轮换、敏感信息脱敏。
- Vault、External Secrets、云 Secret Manager 集成。
- Job 独立 ServiceAccount、镜像允许列表、Pod 安全。
- 网络策略、资源配额、多租户隔离、跨命名空间引用控制。
- OIDC、SSO、OPA、Gatekeeper、Kyverno 集成。

## 可观测性与通知

- 阶段、步骤进度、预计剩余时间。
- observedGeneration、开始与完成时间、执行者记录。
- Conditions、Events、错误原因统一。
- 结构化日志、关联 ID、脱敏。
- Prometheus、Grafana、OpenTelemetry。
- 等待时间、耗时、失败率、恢复次数统计。
- 锁等待、复制延迟、负载、容量监控。
- 长期阻塞、遗留 Applying、状态不一致告警。
- Webhook、邮件、Slack、Teams、飞书、钉钉、企业微信。
- 通知去重、静默、升级、订阅。
- 执行报告、风险报告、故障报告、SLO 和健康检查。

## CLI、API 与界面

- CLI 创建、检查、预演、执行、暂停、恢复。
- kubectl 插件、交互式诊断、本地 dry-run。
- 无 Kubernetes 执行模式、REST API、SDK、事件订阅。
- Web 控制台、项目概览、连接管理与测试。
- SQL 编辑、结构浏览、schema diff。
- 依赖图、时间线、步骤详情、风险和审批页面。
- 日志检索、历史报告、预演结果、人工恢复界面。
- 多环境、多数据库、多集群管理。
- 搜索、标签、筛选、批量操作。
- 国际化、可访问性、键盘操作。

- 迁移目录规范、项目初始化、baseline 生成。
- 既有迁移导入、账本接管。
- Flyway、Liquibase、Atlas 记录导入、ORM 脚本接入。
- schema 历史、快照、差异查询、漂移修复计划。
- 模板、示例库、驱动与规则和通知插件 SDK。
- 插件发现、版本管理、兼容性校验。
- 数据目录、服务目录、应用依赖、工单和事故系统集成。
- AI 辅助 SQL 解释、风险分析、修复建议。
- AI 计划确定性校验与人工审核。

- Helm、Kustomize、一键安装、离线安装。
- 私有镜像仓库、镜像签名、多架构镜像。
- 命名空间级与集群级部署。
- 多副本 leader election、故障切换。
- 多集群控制面、独立代理、高可用。
- 滚动升级、兼容性检查、账本 schema 升级。
- 配置热更新、状态和审计备份恢复。
- 资源清理、历史归档、容量控制。
- 安装前检查、安装后自检、支持包和诊断导出。
- 卸载执行保护与资源保留。
