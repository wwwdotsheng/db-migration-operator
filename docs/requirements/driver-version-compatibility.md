# Driver 版本兼容需求

## 目标

用户在 `spec.driver` 中选择驱动实现。Operator 在继续迁移前确认所选实现兼容实际连接的数据库。

## 需求与验收

- 用户可以按注册名选择同一种数据库的不同驱动实现。驱动名未知时，报告配置错误。
- 每套 Driver 查询服务端的实际版本，并按自己的兼容规则校验。规则覆盖该实现认可的版本格式及发行版标识。
- 版本检查通过后，Operator 继续使用所选 Driver。版本查询失败、版本无法识别或版本不兼容时，Operator 报告相应原因并停止本次迁移。
- 成功结果保留服务端原始版本字符串，供排查问题时查看。
- 验收覆盖支持范围的边界、有效的发行版后缀和无法识别的版本字符串。例如选用 `mysql-8.0` 并连接到 MySQL 5.7 时，应报告版本不兼容。

每套 Driver 的兼容范围和实际验证范围随实现确认。实现方案见 [Driver 设计](../design/driver.md)。
